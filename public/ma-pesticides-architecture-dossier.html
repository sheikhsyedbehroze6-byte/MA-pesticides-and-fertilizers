M.A. Pesticides & Fertilizers (Hari Singh High Street, Srinagar) represents four decades of horticultural trust in the Kashmir Valley. This enterprise web application bridges university-grade plant pathology (SKUAST-K), client-side neural vision, and mathematical tank dilution algorithms into a resilient, offline-first Progressive Web App (PWA) tailored for Kashmiri orchardists operating in remote alpine fruit belts.

Constructed with React 19.2 and bundled via Vite 8.3. Implements declarative routing with React Router v7, smooth hardware-accelerated animations using Framer Motion 12 & GSAP 3.15, an interactive Three.js 0.185 3D orchard scene, and Lucide vector iconography. Renders crisp bilingual typography (English + Kashmiri Nastaliq Urdu).

Tier 2: Real-Time Computational Engines Client Compute

Runs 100% client-side in the browser thread with zero backend roundtrip latency. Hosts the AI Leaf Disease Vision Scanner, the Orchard Spray Dosage Engine, the Weather Spray Feasibility Analyzer, and an autonomous algorithmic Chatbot Advisor capable of site navigation and product lookup.

Precision Tank Dosage Engine & Weather Advisory

Mathematical Dilution Algorithm • Auto-Prescription Bridge • Microclimate Risk Analysis
PAGE 3 OF 5

Underdosing pesticides breeds resistant fungal strains, while overdosing causes foliar chemical phytotoxicity and economic loss. The Dosage Calculator translates SKUAST-K university concentrations into precise volume measurements for Kashmiri 200L barrel spray motors, tractor units, or orchard acreage, seamlessly coupled with real-time microclimate spray windows.

1. Mathematical Dilution Models & Dual-Mode Calculations
Mode A: Spray Tank & Barrel Volume Direct Volume

Farmers select standardized Kashmiri barrel presets (100L, 200L standard drum, 500L, 1000L high-pressure tractor pump) or input custom liters: $$Q_{\text{chemical}} = V_{\text{water (L)}} \times \text{Rate}_{\text{per Litre}}$$ Outputs grams or milliliters, automatically formatting $\ge 1000\text{g} \rightarrow \text{kg}$ and $\ge 1000\text{ml} \rightarrow \text{Liters}$.

Mode B: Land Area & Tree Density Acreage Model

Calculated in Kashmiri Kanals (1 Kanal = $5440\text{ sq ft}$) and tree counts. Calibrated against university empirical spraying metrics: $$V_{\text{kanals}} = \text{Kanals} \times 100\text{L} \quad;\quad V_{\text{trees}} = \text{Trees} \times 12\text{L}$$ $$V_{\text{water}} = \max(V_{\text{kanals}}, V_{\text{trees}})$$

2. The Auto-Prescription Pipeline (AI Scanner $\rightarrow$ Dosage Engine)
When an orchardist clicks Auto-Calculate Dosage for [Disease] in the AI Scanner:
  1. Product Resolution: Mapped pathogen triggers state update with SKUAST-K primary cure (e.g., Apple Scab $\rightarrow$ Superstar Dodine 65% WP @ 1.0g/L).
  2. Category Harmonization: Switches active category filter (Fungicide / Insecticide / Bio-Pesticide) and pre-selects the product card.
  3. Smooth Viewport Scroll: Uses calcSectionRef.current.scrollIntoView({ behavior: 'smooth' }) to position the user at the tank inputs.
  4. Active Prescription Badge: Mounts an informative persistent badge displaying pathogen taxonomy, Urdu disease name, recommended spray window, and mixing precautions.
3. Real-Time Meteorological Spray Advisory Architecture
Microclimate Weather Ingestion Open-Meteo API

Implemented in weatherService.js. Retrieves live hyper-local meteorological forecasts for Kashmir apple zones (Srinagar, Sopore, Baramulla, Shopian, Pulwama, Anantnag). Caches responses in local memory to prevent API rate-limiting during erratic cellular connectivity.

Multivariate Spray Suitability Index Safety Algorithm

Evaluates three physical criteria:
• Wind Speed: Must be $< 10\text{ km/h}$ to prevent spray drift and chemical loss.
• Rain Probability: Must guarantee 4–6 hours rain-free window for contact fungicides, 2 hours for systemic fungicides.
• Temperature: Must remain between $15^\circ\text{C}$ and $25^\circ\text{C}$ to avoid foliar vapor scorch.

2. Crop Pathology & Scientific Taxonomy Key
Apple Scab (Venturia inaequalis) Critical

Urdu: ایپل سکیب (سیب کی خارش)
Symptoms: Olive-green to velvety dark brown lesions; leaf distortion and premature defoliation.
Cure: Dodine 65% WP or Antracol.

European Red Mite (P. ulmi) High

Urdu: سرخ مکڑی (ریڈ مائٹ)
Symptoms: Dull copper-bronzed foliage, fine yellow stippling and webbing under leaves.
Cure: Mitofix (Propargite 57% EC) @ 1.5ml/L.

Powdery Mildew (P. leucotricha) Medium

Urdu: پاؤڈری پھپھوندی (سفید پاؤڈر)
Symptoms: White talcum/flour-like powder coating foliage and young terminal buds.
Cure: Luna Experience (Fluopyram + Tebuconazole).

Alternaria Blotch (A. mali) High

Urdu: الٹرنیریا بلائٹ
Symptoms: Circular brown necrotic spots surrounded by purple halos; severe leaf fall.
Cure: Difenoconazole 25% EC (Score / Willowood).

Peach Leaf Curl (T. deformans) High

Urdu: آڑو کے پتوں کا مڑنا
Symptoms: Severely puckered, thickened, blistered leaves with reddish-pink distortion.
Cure: Copper Oxychloride 50% WP (Blitox).

Woolly Apple Aphid (E. lanigerum) High

Urdu: اُونی مکھو (روئی دار کیڑا)
Symptoms: White cottony waxy clusters along veins, pruning wounds, and bark.
Cure: Cyclone 505 / Imidacloprid 17.8% SL.

3. Chemical Resistance Management (FRAC / IRAC Protocol)

Kashmir's microclimate features intensive spring rain clusters that promote rapid fungicide tolerance if a single chemical family is sprayed repeatedly. The system tracks active chemical groups (FRAC 3 Triazoles, FRAC 7 SDHIs, FRAC 11 Strobilurins, FRAC M Multi-site contacts) and automatically enforces alternating chemical modes of action across sequential calendar sprays.
